# Third-Party Notices

## UI Moments

The loading and interaction animations in `ui-moments.css` / `ui-moments.js`
(Infinity Square Snake boot loader, Pulse Rings sigil-login wait, Text Shimmer
and Text Dots IA thinking states, Cascade hub load, Dash Ring status spinner,
Ripple tap feedback) are adapted from **UI Moments**, an open-source UI
interaction & motion gallery by @guanmo_ai:

- Repository: https://github.com/guanmo-ai/ui-moments
- Live gallery: https://guanmo-ai.github.io/ui-moments/
- License: MIT

Adaptations for Neon Vigil: recolored from the gallery's monochrome to the
site's IA Symbiont theme tokens, retimed, and wired to this site's boot,
sign-in, and hub surfaces. Reduced-motion behavior follows the source.

The UI Moments gallery itself incorporates pieces from LDRS, Loading UI,
SVG Spinners, and Micron.js, which keep their own licenses as recorded in
the gallery's CREDITS.md / THIRD_PARTY_NOTICES.md. Those notices travel with
any of their code used here, per the gallery's terms.
